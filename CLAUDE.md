with code in this repository.

## What this is

`rbcb` is an R package that wraps Brazilian Central Bank (BCB) web
services: SGS time series, PTAX currency rates (old ptax CSV endpoints
and the newer OLINDA OData API), and Focus market expectations (OLINDA
OData).

## Commands

Run from the repo root in R (or `Rscript -e '...'`):

``` r

devtools::load_all()                       # load package for interactive work
devtools::document()                       # regenerate man/*.Rd and NAMESPACE from roxygen
devtools::test()                           # run all tests
testthat::test_file("tests/testthat/test-sgs.R")       # one file (after load_all)
devtools::test(filter = "sgs")             # files matching test-*sgs*.R
devtools::check()                          # full R CMD check (what CI runs)
lintr::lint_package()                      # lint, config in .lintr
rmarkdown::render("README.rmd")            # rebuild README.md - edit README.rmd, never README.md
```

- `NAMESPACE` and `man/` are generated by roxygen — edit the `#'`
  comments in `R/`, then run `document()`.
- `DESCRIPTION` has an explicit `Collate:` field. A new file in `R/`
  must be added there, or the build fails.
- Tests hit the live BCB APIs. Network tests use `skip_on_cran()` +
  `skip_if_offline()`; follow that pattern. `tests/testthat/setup.R`
  sets `options(rbcb_cache = FALSE)` for the test run.
- Bug fixes and user-facing changes go in `NEWS.md`; bump `Version` in
  `DESCRIPTION`.

## Architecture

**HTTP layer (`R/utils.R`).** All downloads go through
`http_download("get"|"post", ...)`. It hashes the call arguments with
`digest` and writes the response to `tempdir()/<hash>`, returning the
file path. If that file exists and `getOption("rbcb_cache", TRUE)` is
TRUE, the request is skipped. Parsers then read from the file path
(`fromJSON(f)`, `read_html(f)`). `rbcb_verbose` option turns on httr
verbose output. `R/rbcb_get_currencies.R` has a second, separate
in-memory cache (`.CACHE_ENV`) for the currency list.

**SGS series — two APIs on the same code.** - Object API:
`sgs(USD = 1, IPCA = 433)` builds an S3 `sgs` list of `sgs_obj` (with
`load_info = TRUE` it scrapes series metadata — description, unit,
frequency — from the sgspub HTML page).
[`rbcb_get()`](https://wilsonfreitas.github.io/rbcb/reference/rbcb_get.md)
is an S3 generic (`R/rbcb_get.R`); `rbcb_get.sgs` returns one tidy
tibble (`date, value, name`).
[`sgs_untidy()`](https://wilsonfreitas.github.io/rbcb/reference/sgs_untidy.md)
splits it into per-series tibble/xts/ts. - Classic API:
[`get_series()`](https://wilsonfreitas.github.io/rbcb/reference/get_series.md)
(`R/rbcb_get_series.R`) is a thin wrapper over the object API. It only
loads metadata when `as = "ts"`, because the `ts` conversion needs the
frequency (`A/Q/M/D`) to set `start` and `frequency` in
`.sgs_convert_split`.

**Currencies.** - `R/rbcb_get_currencies.R`: legacy ptax endpoints (CSV,
Windows-1252 text). `get_currency`, `get_all_currencies`,
`get_currency_cross_rates`. The currency list is fetched from the latest
available daily file, walking back one day at a time until a file
exists. - `R/odata_ptax.R`: OLINDA PTAX API (`olinda_get_currency`,
`olinda_list_currencies`). Returns objects of class `olinda_df`. -
`R/currency_helpers.R`:
[`Bid()`](https://wilsonfreitas.github.io/rbcb/reference/helpers.md) /
[`Ask()`](https://wilsonfreitas.github.io/rbcb/reference/helpers.md) S3
generics over `data.frame`, `xts` and `olinda_df`. - Type A vs type B
quote conventions (currency/USD vs USD/currency) are documented in
comments at the top of both currency files.

**Market expectations (`R/odata-expectativas.R`).**
`get_market_expectations(type, ...)` is the core; the
`get_*_market_expectations` functions are per-endpoint wrappers.
`.build_expectations_url` builds the OData `$filter` from `indic`,
`start_date`, `end_date`, and merges any extra OData params passed via
`...` (e.g. `$top`, `$select`, a user `$filter` is AND-ed). Column names
come back in Portuguese; `keep_names = FALSE` maps them to English via
`change_names`.

**Other.** `R/datasets.R` queries the dadosabertos CKAN catalog;
`R/addins.R` is an RStudio addin (shiny/miniUI, in Suggests) for
searching series.

`legacy/` is gitignored scratch (old scripts, and credential files) —
not part of the package; don’t read it or add it to the build.
