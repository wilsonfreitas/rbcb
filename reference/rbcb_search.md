# rbcb Search

\`rbcb_search(text)\` opens an \[RStudio
gadget\](https://shiny.rstudio.com/articles/gadgets.html) and
\[addin\](http://rstudio.github.io/rstudioaddins/) that allows you to
query for specific terms and see a suitable rbcb command to fetch the
desired data.

## Usage

``` r
rbcb_search(text = "")
```

## Arguments

- text:

  text to search

## Value

Addin has no return
