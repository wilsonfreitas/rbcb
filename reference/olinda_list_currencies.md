# List all currencies

Lists all currencies and presents their name, symbol, numeric code,
country name and county numeric code

## Usage

``` r
olinda_list_currencies()
```

## Value

A `data.frame` with information of all currencies.

The `currency_type` refers to the currency's parity quotation. Parity
quotations relates currency values with USD.

## Examples

``` r
if (FALSE) { # \dontrun{
list_currencies()
} # }
```
