# All currency values

Gets all currency values

## Usage

``` r
get_all_currencies(date)
```

## Arguments

- date:

  reference date

## Value

A `data.frame` with all currency values from the given date. The
currency rates come quoted in BRL.

## Examples

``` r
if (FALSE) { # \dontrun{
get_all_currencies("2017-03-10")
} # }
```
