# rbcb dataset

\`rbcb_dataset(name)\` opens an \[RStudio
gadget\](https://shiny.rstudio.com/articles/gadgets.html) and
\[addin\](http://rstudio.github.io/rstudioaddins/) that allows you to
view a few attributes that help to explain the desired data.

## Usage

``` r
rbcb_dataset(name)
```

## Arguments

- name:

  dataset id (as shown by \`rbcb_search()\`) or name

## Value

Addin has no return
